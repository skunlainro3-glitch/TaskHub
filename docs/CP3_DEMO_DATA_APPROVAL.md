# Mẫu duyệt khi bổ sung dữ liệu demo

**Cập nhật 28/10/2026:** bộ giả lập 3 tour/3 công việc/3 phiếu B2B đã có quy ước được chủ dự án cho phép quyết định; xem [dữ liệu của nhóm](OWNER_DEMO_DATA_2026-10-18.md) và [bàn giao Tuấn/Huy](CP4_TUAN_HUY_HANDOFF.md). Không phải điền lại mẫu này để chạy bộ demo đang có. Hai phiếu đã xác nhận được tính trong số khách của tour; phiếu thứ ba còn chờ, chưa giữ chỗ.

Mẫu dưới chỉ dùng nếu nhóm muốn thêm tour hoặc kịch bản khác. Danh mục 13 tour Én Việt có nội dung tham khảo, chưa có ngày đi chính xác, sức chứa, khách đã giữ chỗ hoặc lịch trình từng ngày được nhóm xác nhận cho hoạt động mở bán. Không tự chuyển nội dung danh mục thành tồn kho hoặc tour đang bán. Ảnh nguồn đang lỗi cần được cung cấp lại; giao diện hiện dùng minh họa có nhãn.

## Một tour để demo

| Trường | Thông tin nhóm điền |
| --- | --- |
| Mã/tên tour từ danh mục, hoặc tên tour riêng | |
| Điểm đến và thời lượng | |
| Ngày đi cụ thể YYYY-MM-DD | |
| Giá VND đã xác nhận, không dùng giá chưa rõ | |
| Sức chứa | |
| Tổng khách đã giữ trong kịch bản; ghi rõ đã bao gồm khách B2B hay chưa | |
| Mô tả và lịch trình từng ngày đã duyệt | |
| Người duyệt, ngày duyệt | |
| Được phép công khai trên portal hay chỉ dùng local | |

## Một công việc và một tình huống B2B

| Trường | Thông tin nhóm điền |
| --- | --- |
| Tên việc và tour liên quan | |
| Người phụ trách và hạn YYYY-MM-DD | |
| Tên đối tác ghép tour | |
| Số khách ghép, không vượt chỗ còn lại | |
| Giá net thỏa thuận mỗi khách, VND | |
| Số thu lũy kế dùng cho tình huống trình diễn; đánh dấu giả lập nếu không phải giao dịch thật | |
| Ghi chú điều khoản và người duyệt | |

Sau khi nhóm điền, Tuấn dùng danh mục hoặc mẫu CSV tải trong Nhập Excel để nhập tour nháp, kiểm tra rồi mới công khai nếu được duyệt. Tạo công việc/phiếu B2B từ dữ liệu đã duyệt. Phiếu chờ chưa giữ chỗ; xác nhận mới giữ chỗ. Tài khoản demo tách khỏi người khảo sát và không đưa vào số người thử thật.
